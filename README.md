# SmartMoney AI – Personal Financial Planning Assistant

## Project Introduction
SmartMoney AI is a personal financial planning assistant developed using Python and Streamlit. It helps users manage their monthly income, expenses, budgets, savings, and financial goals.

## Project Objectives
- Track monthly income and expenses.
- Prepare monthly budgets.
- Calculate monthly savings.
- Monitor financial goals.
- Provide personalized financial recommendations.

## Features
1. **Expense Tracking:** Record and analyze monthly expenses.
2. **Budget Planner:** Compare planned budgets with actual expenses.
3. **Savings Planner:** Track savings goals and estimate completion time.
4. **Financial Summary:** Display income, expenses, and savings.
5. **Recommendations:** Provide rule-based financial suggestions.
6. **CSV Reports:** Download expense and budget reports.

## Technologies Used
- Python
- Streamlit
- Pandas
- Excel

## How to Run the Project

### Step 1: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the application
```bash
python -m streamlit run app.py
```

### Step 3: Open the application
Open the local URL displayed in your terminal, usually:
`http://localhost:8501`
